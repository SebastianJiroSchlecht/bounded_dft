# Bounded Magnitude DFT
Accompanying code to S. J. Schlecht, V. Välimäki, and E. A. P. Habets, "Bounded-Magnitude Discrete Fourier Transform [Tips & Tricks]," IEEE Signal Processing Magazine, vol. 40, no. 3, pp. 46–49, 2023. [doi:10.1109/MSP.2022.3228526](https://doi.org/10.1109/MSP.2022.3228526)

The code provides full reproducibility of the paper figures. Two demo files are included
- demo_fullExample.m
- demo_bounds.m

The code has been developed and tested on MATLAB R2022a on MacOSX Monterey.
